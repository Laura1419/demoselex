### Encoding and K rule

[inference] For each window use ALL panel individuals and ALL biallelic SNPs with finite mean dosage and nonzero variance outside the exclusion. Missing/invalid (<0 or >2) dosages become the all-panel marker mean only for encoding; retain per-person observed-call fractions separately. Standardize by marker empirical standard deviation (floor .1 to limit rare-variant leverage). Stream 256-variant batches into a 48-dimensional seeded Gaussian random projection (each coefficient N(0,1/48)); divide by sqrt(number of features). This is a bounded-memory approximation to genotype Euclidean distances; do not claim haplotype phase. Use the same per-variant seeded projections for both sizes and exclusion-off checks. No genotype marker is selected by association, age or published labels.

[inference] Fit MiniBatchKMeans on all individuals for K in {2,4,6,8}, batch size 2048, n_init=5, max_iter=100, seed 20261009. Select maximal silhouette on a fixed random sample of up to 1500 panel individuals (evaluation subsampling only, never a reference subset); ties within .01 choose smaller K. Primary is 1 Mb flanks/1 Mb canonical span. Report all K silhouettes, chosen K, ARI between sizes at primary K, between selected sizes, versus nearest alternative K(s), and across a second clustering seed. No post-result K tuning.

[inference] Structural encoding retains every H1/H2 slot and all labels in the entire supplied archive, tabulates counts by source/type/population, and reports the EXACT overlap with the full bundle. ### Validation gates (a)–(d), BEFORE AMY outcome testing

[inference] (a) Primary silhouette >=.10, normalized mutual information (NMI) versus published AADR group >=.10 and country >=.05, among mapped annotated individuals; report label mapping denominators, full cluster/group/country/date composition. Sequencing technology (ID suffix .DG/.SG versus other) and bibliographic/data-source composition are batch proxies, not verified sequencing batches. Weighted within-AADR-group technology NMI must be <=.20 among groups with >=20 persons and >=2 technologies; absence of informative metadata makes this gate unresolved/failing. This checks rather than assumes clusters reproduce structure.

[inference] (b) ARI between sizes at the SAME primary K >=.65; ARI versus each nearest alternative K >=.60; second-seed ARI >=.80. Also report selected-K size ARI and cluster composition, not merely label agreement. These are new clustering gates, not the failed painter's proportions gates.

[inference] (c) Exact exclusion audit: zero forbidden features, tested SNP absent; software perturbation invariance. Independent negative control: permute a fixed balanced binary pseudo-variant over all panel individuals, report cluster-explained variance eta-squared and its 199-permutation upper-tail P; require P>=.01. This guards artefactual cluster/variant association; it does NOT establish independence of all residual LD. Exclusion-off ARI is a diagnostic, not permission to retain the tested allele.

[inference] (d) Every panel individual receives an assignment; >=99% have observed call fraction >=.95 in the outside-exclusion background SNPs. Report minimum/median, usable count and full denominator. Full imputation fixes input coverage only, not ancient imputation accuracy.

### Statistics, null, floor, decision

[inference] Per validated locus/background report ALT or structural-allele frequency, individuals, chromosome-slot counts, dated n and BP range. For temporal tests ancient dates only; modern individuals remain in clustering but not the temporal regression. Time=-BP/1000 (forward kyr). Regress allele fraction on time plus cluster intercepts; common within-background slope, HC3 SE and two-sided t P. Separately fit within each cluster with n>=30 and >=2 kyr age span; insufficient cells are explicitly unevaluable. Null: no frequency change conditional on the empirical background. Related panel rows are not independent chromosomes, and HC3 does not correct all kinship, demography or imputation uncertainty; this is diagnostic, not a calibrated selection discovery test.

[inference] BEFORE reporting any slope interpretation, report 80%-power minimum detectable slope (MDE): (t_.975,df + z_.80)*HC3_SE in frequency/kyr and twice that for 2 kyr. Also report binomial ideal floor using observed p and residual temporal information: 2.802*sqrt(p*(1-p)/(2*sum(time_residual^2))). Empirical HC3 floor takes precedence. n<30, singular design, constant allele or insufficient age span yields NA, not a zero floor.

[inference] Background-sharing/recurrence descriptive statistic: number of clusters with expected >=5 ALT/structural allele copies and >=5 alternative copies, frequencies and effective support exp(entropy of allele-copy cluster shares). This is **multi-background carriage**, NOT proof of independent molecular origin: recombination, migration and unphased partner chromosomes can distribute one origin among several backgrounds. Origin recurrence requires sequence-level structure evidence, cannot follow from clustering alone. Use published structure distance data to test label identity where linkable, not assert recurrence from labels.

[inference] Run canonical controls identically; positive-control success is >=1 identifiable positive forward ALT slope with P<.05 and >=1 locus with multi-background support, subject to its own gates. Failure is reported, not used to select K. For AMY, if ANY gate fails or is unresolved: STOP AMY background-conditioned frequency, temporal and recurrence interpretation; report only machinery diagnostics, structural input inventory, and outcome-blind design power (observed p only if already published baseline). If all gates pass, require a within slope exceeding its MDE and P<.05 for a detectable within-background signal; otherwise state underpowered or null. No independent-origin or selection claim without separate calibration.

[inference] Compare against existing global-label results without rewriting them: component AMY1 means; A<=2 X-equivalent 3.64 versus cutoffs 3.16/5.45; GRM retention ~97%; carriage ~94%; primary A<=1 within .049 versus .146/kyr floor (do not conflate A<=2 with this primary). Released AMY scan 2204 SNPs, max |X|3.794956889, zero >5.45; canonical maxima 16.52/16.15/13.15/5.99. Report any numeric disagreement explicitly. Record elapsed/RSS/window variant counts for genome-wide cost estimates; feasibility of imputed diplotype clustering does not establish phased whole-panel haplotype feasibility.
