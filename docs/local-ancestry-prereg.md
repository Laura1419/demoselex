# Local ancestry Stage 1 — preregistered protocol

## NEW PROTOCOL — 2026-10-09, before genotype analysis/results

[inference] This is an **unphased, in-house window HMM approximation, NOT RFMix/FLARE**. It cannot identify which AMY structural haplotype resides on which ancestry chromosome. Ancestry sources are empirical proxies, not discrete prehistoric biological populations. A validated diploid local-composition covariate is not itself proof of allele change on a phased, fixed haplotype ancestry background. Stage 1 will not conflate these claims.

### Reference populations and exclusions

[inference] Use ONLY these exact AADR 1240K published `.ind` labels: WHG = `France_Mesolithic`, `Luxembourg_Loschbour_Mesolithic`; EHG = `Russia_Karelia_Mesolithic`; FARM = `Turkey_N`; IRAN = `Iran_GanjDareh_N`; STEPPE = `Russia_Samara_EBA_Yamnaya`. IRAN brackets Iran/CHG-related variation but is not asserted equivalent to CHG. STEPPE is itself historically admixed and is a distinguishable source proxy, not an independent primordial ancestry. Use assessment starting `Pass`; discard EVERY individual with a nonempty/non-`..` Family relations field (annotation column 31). Deduplicate biological Individual ID (column 2), retaining the representation with most reported 1240K SNP hits (column 26), then genetic ID lexicographically. Unknown relationships remain possible. Report exact per-label counts and BP ranges before/after filtering.

[inference] Split eligible biological individuals within each source, sorted by ID, with RNG seed 20261009: hold out max(2, ceil(n/4)), leaving at least three training individuals. Train frequencies and select AIMs on training ONLY; held-out individuals never contribute source frequencies. All mapped AMY ancients (not only the previous 225) are targets; matches use exact genetic/biological ID, otherwise unique suffix-stripped ID; ambiguous matches rejected. Targets coinciding with training references are removed from AMY inference.

### AIM panel

[inference] Autosomal AADR biallelic A/C/G/T SNPs; source call fraction >=0.5 in EACH training source and >=3 observed training individuals/source; call fraction >=0.2 among mapped AMY targets; maximum-minus-minimum source ALT frequency >=0.45. Pseudohaploid calls contribute dosage/2 as ONE sampled allele; `.DG`/`.SG` contribute diploid counts (two alleles). Estimate p with Jeffreys smoothing (ALT count+0.5)/(allele count+1). Rank eligible SNPs by maximum-minus-minimum p, greedily keep at least 50kb between markers on each chromosome, then coordinate sort. Save source p, per-source call fractions, target call fraction, divergence, and descriptive equal-source Fst = Var(p)/(pbar*(1-pbar)); this is not unbiased Weir–Cockerham Fst. Exclude chr1:103.5–104.5Mb from genome-wide validation/PC summaries, NOT from painting the AMY vicinity.

### HMM and sensitivity

[inference] States are unordered ancestry pairs (15 pairs from five sources), giving one source per inferred chromosome but no phase. Nonoverlapping 2Mb physical windows; reset HMM at chromosome boundaries. Diploid emissions at SNP j in pair (a,b): P(0)=(1-pa)(1-pb), P(1)=pa(1-pb)+pb(1-pa), P(2)=pa*pb. Pseudohaploid emissions use Bernoulli q=(pa+pb)/2 on dosage/2; missing calls contribute zero. Sum log likelihood, multiply by 0.25 (fixed tempering), use an equal initial state prior. Transitions have log penalty 4 per changed ancestry slot, minimized over both pair alignments, row-normalized. Compute Viterbi and forward–backward marginal probabilities; local source dosage is posterior expected chromosome fraction. Minimum five observed AIMs/window: otherwise emission is flat, report low support and exclude such windows from ancestry summaries; HMM interpolation does not manufacture coverage. Targets need >=100 informative windows and >=20% observed AIMs genome-wide. AMY covariate averages posterior composition over overlapping supported windows in 103.5–104.5Mb, requiring >=10 observed AIMs across those windows.

[inference] SNP independence is wrong because of LD: correlated evidence overstates precision and creates overly confident segments. 50kb thinning and 0.25 tempering reduce but do not calibrate this problem. Physical switches are not a recombination clock; no segment dating is attempted. Source finite-sample uncertainty and imputation uncertainty are not propagated. Sensitivity grid: window sizes 1, 2, 4Mb crossed with switch penalties 2, 4, 8; primary 2Mb/4. No parameter tuning after validation.

### Validation gate BEFORE any AMY regression

[inference] Required: at least two evaluable held-out individuals/source; held-out dominant global-source confusion matrix accuracy >=80% overall AND >=60% per source; median correct-source chromosome fraction >=0.60 per source. Negative control: held-out WHG with highest AIM call rate must have WHG fraction >=0.80 (selected without ancestry outputs). Genome-wide posterior composition must predict published source labels >=80% accuracy under held-out dominant classification, and independent-marker PC position must agree: squared multivariate correlation (in-sample R² from first three PCs regressed on four ancestry fractions) >=0.50 averaged across the three PCs. PCs use separate autosomal markers >=200kb apart, excluding all AIMs and AMY, mean-imputed/standardized; reference training+heldout+eligible targets, maximum 10000 markers. This association is descriptive, not independent ancestry truth. Stability: all eight alternative settings must have median held-out global-fraction L1 difference <=0.25 and dominant-source agreement >=80% against primary. Report target global and AMY-vicinity stability too. **If ANY gate fails: write failure, STOP AMY analysis, do not report AMY frequency/regression estimates from this painter.**

### AMY analysis, null, detection floor, decision

[inference] Only AFTER validation: extract released archive tables into `data/derived/local_ancestry/scratch/`. Primary B dosage = number of H1/H2 labels with leading AMY1 integer >1 (A=H1^a); prespecified sensitivity A<=2 to compare prior X-equivalent3.64. Structural tables and metadata are joined on sample; no numeric copy-number surrogate used as haplotype dosage. Fit B dosage/2 = intercept + four local chromosome fractions + forward time (-BP/1000), OLS with HC3 covariance. Null beta_time=0 conditional on measured local composition, two-sided alpha .05. Report pooled and global-label fixed-effect fits on the IDENTICAL supported cohort, plus prior 225-person global-label result. Tables by dominant local source and BP bins [0,2000,4000,6000,8000,10000,infinity), with n/B counts; these are individual diplotype frequencies conditional on local composition, NOT phased ancestry-specific allele counts. Descriptive per-source time slopes only where n>=10 and >=1kyr span. No genome-wide application.

[inference] Before interpreting P: 80%-power approximate minimum detectable frequency slope = (t(.975,n-rankX)+normal(.8))*HC3 SE_time; ideal independent-binomial floor = 2.802*sqrt(p*(1-p)/(2*sum(residualized_time²))). Report observed frequency, n, design rank, retained time information, 2kyr floor; approximate Wald power is not drift/kinship-calibrated power. If design rank deficient or fewer than30 supported targets: no identifiable AMY test, report limitation. Significant time term with matching slope sign in all sensitivity fits indicates persistence conditional on local ancestry approximation, NOT selection or phased fixed-background proof. Nonsignificant slope below floor means underpowered, not absence. Compare numerical pooled/local/global coefficients and floors; do not transport the earlier94% decomposition to a different cohort. A genuine phased-background claim requires phasing/linkage of structural haplotypes to ancestry segments beyond Stage1.
