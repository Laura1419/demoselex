# Two-channel preregistration — NEW SECTION, 2026-10-09

[observation] Written before computing any two-channel results in this session. Only source code, schemas and prior reports were read. This is a local pre-run registration, not an externally immutable registry. Seed 20261009; 4096 correlated-null draws per covariance scenario. Results will be appended separately, never substituted for earlier authors' conclusions.

## (a) WITHIN
[inference] Forward time t=-BP/1000. Measured component baseline mu_k=mean(y among called component members); x_i=t_i-mean(t|component,called). beta_within=sum(x_i*(y_i-mu_k))/sum(x_i^2), using the measured-baseline construction in analysis/mixture_null.py and analysis/prioritization_score.py. SNP units ALT frequency/kyr, AMY units diploid copies/kyr. SNP support remains >=8 calls, >=3 dates, >=2kyr per deme, >=100 people and >=2 demes overall; reuse already-scored within estimates/SE, not new fitting to Akbari labels. AMY uses all valid ancient p2 labels (including singleton CHG for the within fit).

## (b) BETWEEN / CARRIAGE
[inference] Predict m_i=mu_group(i); equivalently, each date slice has m(t)=sum_k w_k(t)*mu_k, w being called-member counts divided by total called people. beta_between=Cov(t,m)/Var(t) on the same supported SNP members, or all AMY members. Means are actual component-member measurements, NOT free donor-frequency parameters optimized to absorb a temporal trend. The already-released composition_slope implements this SNP channel. Report its uncertainty as descriptive rather than causal; measured means reuse the locus's data. SNP donor means for ordering are recomputed from cached individual genotypes, never inferred from X.

## (c) TOTAL and scaling identity
[inference] Report beta_total=beta_within+beta_between exactly as requested; neither channel is zeroed or penalized by the other. This additive index is NOT the pooled observed regression: within centring changes time information. Also report beta_within_pooled_contribution=beta_within*Sxx_within/Sxx_pooled and beta_pooled=that contribution+beta_between, where available. Prevent mistaken causal percentages from summing slopes with different denominators. Opposite signs are retained, and ranking combines magnitudes rather than cancelling them.

## (d) ORDERED SERIES and real drift null
[inference] Order donors by mean called-member forward date. Primary statistic is relatedness-discounted Kendall concordance C=sum_{a<b}(1-R_ab)*sign(mu_b-mu_a)/sum_{a<b}(1-R_ab); zero differences earn zero. Report Spearman rho and concordant successive-step fraction too. Test absolute C (two-sided SNP ALT orientation and AMY), retaining signed C and rho. Donors require >=8 called people; SNP ordering uses the same supported demes. AMY ordering excludes CHG n=1, which remains in within/between fits. High R pairs contribute little, not additional independent replication.

[inference] Measure genetic covariance using data/derived/traj_relatedness.tsv, whose genome-background calculation in analysis/traj_relatedness.py excludes AMY/MHC. Map rebuilt demes and AMY p2 labels to old trajectory memberships by biological ID (strip sequencing suffix), averaging trajectory covariance with membership weights. This is a proxy, not a genealogy; report coverage. Missing mapped components receive a common latent background (correlation .75 to other unmapped groups) rather than independent ancestry. Project the proxy to positive semidefinite and renormalize. Archive the matrices/coverage. Report N_eff=K^2/sum(R). Discount nested ancestry in BOTH statistic and correlated null; do not equate dates/labels with independently formed lineages.

[inference] Real null: zero-direction correlated Gaussian drift in donor trait/frequency deviations, with covariance (1-lambda)*R + lambda*B plus donor sampling diagonal 1/n; B_ab=(min(u_a,u_b)+1)/sqrt((u_a+1)*(u_b+1)), u=forward date minus earliest date in kyr. B represents cumulative shared chronological drift, explicitly allowing inherited/nested donors to produce trends neutrally. lambda=0,.5,1 is a prespecified sensitivity grid, NOT selected for a good result. At each scenario normalize covariance diagonals and simulate 4096 draws; each draw is ordered by the actual donor dates and evaluated with the SAME C weights. P=(1+#|C_null|>=|C_observed|)/(4097). Primary ordering P=max across scenarios, so significance must survive both genetic and shared-history drift assumptions. No mean drift direction, no fitted per-locus drift covariance. Common scale does not affect this sign statistic. Conditional Gaussian drift is a real, explicit, non-independent-donor null, NOT a calibrated Wright–Fisher/LD-honest genome-wide discovery null. Selection evidence can be model-dependent; AMY CN has no calibrated evolutionary-process null here.

## (e) Inclusive prioritisation, costs and falsification
[inference] Define z_within=abs(beta_within)/existing corrected_SE (AMY HC3); z_between=abs(beta_between)/s_between, where SNP s_between is the RMS between slope over candidate-independent controls, AMY uses the member-stratified 1000-bootstrap SE (seed+1). This measures background-relative carriage magnitude, not significance. Score=log1p(z_within^2)+log1p(z_between^2)+max(0,-log10(P_order)-log10(20)). Both channels contribute, ordering boosts rather than excludes. Sort descending with locus ID tie-break. Large within means z_within>=2; large between z_between>=2; small means <2. Report carriage-class (large between/small within), within-class (reverse), both-large and neither; sign-disagreement separately. Ordered carriage candidates additionally require P_order<=.05. Every genome-wide count/proportion/enrichment has the matching control-locus pass fraction; controls defined as merged-panel |X|<3.16 (NOT guaranteed neutral). Akbari strong |X|>5.45 (pi>99%), moderate 3.16<=|X|<=5.45 (50%-FDR boundary); X is never centered.

[inference] False positives are an accepted downstream follow-up cost. Report observed control pass rates for classes, ordering, inclusive top decile, and top-decile ordered carriage; these are not FDR. LD: aggregate to 250kb blocks, choose each block's maximum-scoring representative; control-block proxy uses blocks containing ONLY control-panel variants. Report corresponding fractions and top block list. A calibrated LD-honest block drift null remains unavailable. Agreement with Akbari reuses the same imputed genotypes and is NOT independent validation; earlier top-N bootstrap retention 43.7% remains a warning, not a new stability estimate.

[inference] Falsifier: carriage-with-ordering is not supported by this test if C is ordinary under either prespecified nested/shared-drift scenario (primary P>.05), if ordering disappears after correlated-donor weighting, or if candidate/control pass rates do not distinguish candidate prioritisation. This does not refute selection in an unsampled donor; it falsifies claiming THIS ordering as evidence beyond this null. Large between with robust significant ordered progression IS a candidate selection signal, not a dismissal; large carriage WITHOUT ordering/within/independent functional evidence is descriptive turnover, not itself selection evidence. Independent ancestry estimates, CN haplotype identity, modern phenotypes and demographic/LD calibration are required for causal/discovery claims.
