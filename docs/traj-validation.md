## Verdict: **[observation] NOT INTERPRETABLE — revise**

Trajectory 0 contains 9,648 of 10,369 individuals and spans the entire 65,000-year
record; trajectories 3 and 4 contain 5 and 2 individuals. This is a single dominant
connected component plus fragments, not a set of population paths through time. The
apparently high bootstrap ARI is not reassuring, because a degenerate clustering that
puts almost everyone in one bucket is stable by construction. The parametric ARI of
0.519 confirms real instability once parameters change.

Labelling this a pass would be exactly the failure the plan warns about, so Decision 1
is recorded as **revise**, and no locus analysis (AMY, canonical, Akbari) may run on
v1 trajectories.

## Diagnosis

1. **Moderns are included.** Individuals with date 0 (present-day) are drawn from many
   source populations and glue the graph together; they should be either removed or
   handled as a separate terminal layer.
2. **No within-trajectory continuity requirement.** The time-window constraint stops
   *contemporaneous* merging but never requires that a trajectory be a *sequence* of
   temporally ordered samples that are more genetically continuous with one another
   than with competing contemporaneous samples. The largest connected component
   therefore absorbs the bulk.
3. **`k` controls cluster count, not interpretability.** Choosing k cannot prevent a
   cluster from spanning the whole record.
4. **Modern-dated density.** `median date = 0` for three of five trajectories means the
   sample-time distribution itself (a large modern block) drives the split.

## Required changes for v2 (stage A)

- Exclude modern individuals (date == 0) from trajectory inference, or treat them as a
  separate terminal layer; use the 19,029 non-modern usable individuals.
- Replace k-means-on-time-windows with a **path/sequence** construction: forward-in-time
  edges only, edge weight from genome-wide genetic distance (not calendar time alone),
  with an explicit maximum temporal gap and a maximum total temporal span per trajectory.
- Impose a **minimum trajectory size** and require each trajectory to be temporally
  ordered and locally continuous (successive samples within a genetic-distance
  quantile of each other).
- Validate against known West Eurasian structure (e.g. does a WHG-like, an
  early-farmer-like and a steppe-like path emerge without using those labels?) and
  report bootstrap ARI plus per-trajectory temporal span and genetic coherence.
