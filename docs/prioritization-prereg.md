## Purpose and frozen inputs

[inference] This is a ranking tool for downstream modern phenotype work: precision is reported, NOT a test whose FDR is claimed. False positives are expected and acceptable. A carried-in allele remains eligible. All earlier conclusions are untouched.

[inference] Use the 42 previously validated longitudinal paths and exact Akbari sample-ID matches, individual ALT dosage/2, forward time -BP/1000, measured component-member means and HC3 SEs from analysis/mixture_null.py. The primary null is exactly the previously calibrated pgen **empirical common-slope variance law**: V=HC3_SE²+tau² AF(1-AF), freezing tau² from the saved TRAIN-only result (held-out nominal rate 3.85%; AADR 6.08%). It is NOT a drift+jump path likelihood: it has no explicit jumps, no lineage-specific drift and no path shape. Those omissions motivate a separate shape modifier and independent drift/jump simulations.

[inference] The alternative is a symmetric mixture of two sustained directional common slopes +a and -a with equal prior weight. Freeze a=sqrt(mean TRAIN beta²), measured from the same old training controls, before scoring any new locus. LLR=log[(N(beta;a,V)+N(beta;-a,V))/2]-log N(beta;0,V). No direction, donor, drift strength, jump location or selection amplitude is fitted to improve the likelihood of a scored locus. Observed common/per-lineage slopes and HC3 SEs are summary statistics, not optimized alternative-model parameters. Component frequencies must be measured at the locus; their constant uncertainty cancels through within-group centring. Per-locus HC3 is a sampling estimator, not a demographic tuning parameter.

## Graded components and shape

[inference] Support: each lineage >=8 called people, >=3 dates, >=2 kyr; >=100 total people and >=2 lineages. AF must be strictly between 0 and 1, not restricted to [.1,.9], so rare selected alleles are not mechanically removed. Missing/negative dosages are excluded. No p-value threshold. Embedding SNPs are excluded from the new panel.

[inference] Magnitude component: |beta| and |beta|/sqrt(V); evidence component: LLR. For each supported lineage j compute q_j=Phi(sign(beta)*beta_j/sqrt(SE_j²+tau² AF(1-AF))). Consistency C=mean(q_j); four of six aligned lineages receive graded credit, never require unanimity. Uncertain near-zero slopes contribute about .5.

[inference] Use the eight measured background-PC means per lineage to construct R_jk=exp(-||PC_j-PC_k||²/(2*d²)), d=median nonzero pair distance, R_jj=1. N_eff=(trace R)²/trace(R²), recomputed by submatrix for supported lineages. This participation-ratio proxy discounts genetic similarity but does not establish independent drift histories. Breadth B=N_eff/K_full (K_full=42), kept separate from C.

[inference] Shape uses measured temporal-node means, >=3 nodes each >=3 calls. Sort nodes forward in time. D=sum|successive AF differences|; monotonicity=|net difference|/D (0 if D=0). Jump concentration=max|difference|/D; expected largest ramp share=max(time gap)/total span. Smoothness=clip((1-concentration)/(1-expected largest ramp share),0,1). Shape H=mean across informative lineages of monotonicity*smoothness (0 if no informative lineage). A time-proportional ramp scores 1, a pure one-step change 0, jitter is penalized continuously. This descriptive component has no locus-fitted step location or shape likelihood; three nodes have limited resolving power. Emit monotonicity and smoothness separately.

[inference] Carriage: measured baseline composition slope b_comp from member means on pooled time; within contribution b_within=beta*Sxx_within/Sxx_pooled. W=|b_within|/(|b_within|+|b_comp|), 0 if both zero. This algebraic descriptive decomposition is not causal ancestry attribution. Carriage weight=.25+.75W, never zero. Primary total=LLR+log(.25+.75C)+log(.5+.5B)+log(.25+.75H)+log(.25+.75W). Sensitivity: use .5+.5W and 1 (no carriage penalty), changing nothing else. All components and sensitivity ranks are output. No score tuning on controls.
